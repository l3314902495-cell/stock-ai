## stocks（当前瓶颈：收益不足，年化需 ≥ 基准 60%）

1. **200 日均线加缓冲带**：跌破均线 ×(1−x) 才卖、站上均线 ×(1+x) 才买（x ∈ 1%/2%/3%）。依据：减少在均线附近的来回交易与成本；实验 #2 显示 XLP/XLU/XLB 在均线附近反复打脸（每个约 88 笔交易、年化仅 1~2%）。
2. **月末确认**：只在每月最后一个交易日判断是否持仓。依据：经典的 10 个月均线择时，交易次数大幅减少。
3. **宽基做择时、行业做轮动**：持有近 6~12 个月动量最强的前 3 个行业 ETF，叠加 SPY 趋势过滤。依据：行业动量有长期研究支持；防御型行业单独择时效果差。
4. **均线趋势 + 波动率目标，提高目标波动率**（0.15~0.25）并只在高波动时降仓。依据：基线 voltarget 回撤最低但仓位太轻导致收益不足。

## crypto（当前瓶颈：回撤过大，需 ≤ 约 52%）

1. **BTC 大盘过滤**：只有 BTC 在 200 日均线之上时才允许持有山寨币。依据：山寨币与 BTC 高度相关，熊市中跌幅更大。
2. **sma_trend / donchian_atr 叠加波动率上限**：仓位 = min(1, 目标波动 / 实现波动)，目标 0.6~1.0。依据：只在极端波动时降仓，尽量保留收益。
3. **单币仓位上限 / 去掉流动性差的币**——注意：改动资产池属于修改评测，不允许；只能在策略内部对单币降权。
4. **sma_trend 与 donchian_atr 信号平均（组合）**。依据：两者入场离场时点不同，组合后回撤可能更低。

## 两组通用

- 信号组合（多个简单策略取平均仓位），通常比单一策略更稳
- 离场改为"收盘跌破 N 日最低收盘价"（更慢的离场，减少被洗出）
